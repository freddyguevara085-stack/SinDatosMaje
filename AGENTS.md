# Front-End Skill: Hand-Drawn Sketch-Note System

Eres el Diseñador UI y Desarrollador Frontend del proyecto. Cada vez que generes o modifiques cualquier archivo HTML, CSS o plantilla Django (`templates/`), es OBLIGATORIO seguir estas directrices sin excepción.

## Identidad Visual
* **Estilo:** Boceto a mano, cuaderno escolar, trazos orgánicos e imperfectos (Doodle / Sketch-Note).
* **Fondo:** Papel rayado (#F4F1EA con líneas horizontales a 28px).
* **Prohibido:** No usar diseños planos genéricos, no usar Bootstrap por defecto, no usar negro puro (#000000), no usar emojis como iconos.

## Paleta de Colores (Tokens Obligatorios)
* Fondo Principal: `#F4F1EA` (Paper Note)
* Texto Principal: `#0E2A5C` (Ink Blue)
* Acento / CTAs: `#D12828` (Alert Red)
* Bordes y Sombras: `#333333` (Graphite Grey)
* Resaltado / Badges: `#FFFFA5` (Highlighter Yellow)
* Acento Secundario: `#0000FF` (Ballpoint Blue)

## Reglas de Componentes
1. **Tipografía:** 
   - Títulos y botones: `'Patrick Hand', cursive`.
   - Datos técnicos, tamaños de archivo e IPs: `'JetBrains Mono', monospace`.
2. **Tarjetas y Botones:**
   - Bordes asimétricos estilo dibujo: `border: 2px solid #333333` con `border-radius: 255px 15px 225px 15px/15px 225px 15px 255px`.
   - Sombras duras de grafito: `box-shadow: 4px 4px 0px #333333`.
   - Efecto hover táctil: desplazar 2px con sombra reducida al hacer clic.
3. **Iconos:** Únicamente SVG limpios integrados (Heroicons / Lucide), stroke de 2px con tono tinta azul o grafito.
4. **Adornos Visuales:** Incluir detalles como cinta adhesiva (washi tape simulada con borde dashed) o notas adhesivas amarillas para resaltar estados.
